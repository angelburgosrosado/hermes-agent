# Sub-skill: Promotional Material

Generates campaign copy, ad scripts, flyers, landing page sections, and event materials.
Always read `BRAND.md` in full before generating any content.

## When to use
- Writing ad copy (see also the `ads` skill for full campaign strategy)
- Drafting landing page hero sections or campaign pages
- Creating flyers, one-pagers, or event collateral
- Writing launch announcements or product update copy
- Generating campaign theme/concept copy

## Voice constraints (from BRAND.md)
- Confidence without hyperbole — every claim must be supportable
- Benefit-first, proof second, CTA third
- Urgency must be real — do not manufacture scarcity or deadlines that don't exist
- Use Primary Message as the anchor for every campaign

## Frameworks

### PAS (Pain → Agitation → Solution) — best for problem-aware audiences
```
Pain:      [Name the specific problem the reader has right now]
Agitation: [Show what happens if they don't solve it — cost, risk, frustration]
Solution:  [Introduce the product as the resolution — specific, benefit-led]
CTA:       [One clear action]
```

### AIDA (Attention → Interest → Desire → Action) — best for cold/unaware audiences
```
Attention: [Hook — unexpected stat, bold claim, or relatable scenario]
Interest:  [Why this matters to them — connect to their goal or pain]
Desire:    [What life looks like after — benefits, proof points, social proof]
Action:    [Specific CTA with low friction]
```

### BAB (Before → After → Bridge) — best for transformation stories
```
Before: [Current painful state — be specific, not generic]
After:  [Desired end state — vivid, concrete, measurable where possible]
Bridge: [The product as the path from Before to After]
CTA:    [One action]
```

## Format templates

### Landing page hero
```
Eyebrow:    [Optional short label — 2-4 words, caps, e.g., "NEW FOR 2025"]
Headline:   [Primary benefit — ≤10 words]
Subhead:    [Who it's for + what they gain — 1-2 sentences]
Proof line: [Social proof or stat from BRAND.md]
CTA:        [Primary button text] + [Secondary link text if needed]
```

### One-pager / flyer
```
Header:    [Brand name + tagline]
Headline:  [Primary message]
Body:      [3 benefit bullets — feature: benefit format]
Proof:     [Quote or stat]
CTA:       [Action + contact/URL]
Footer:    [Legal line if required per BRAND.md Compliance section]
```

### Event / webinar promotional copy
```
Title:     [Outcome-focused title: "How to [achieve X] in [timeframe]"]
Hook:      [Who should attend + what they'll leave with]
What you'll learn:
- [Takeaway 1]
- [Takeaway 2]
- [Takeaway 3]
Speaker:   [Name, title, credential]
Date/time: [Placeholder]
CTA:       [Register now / Save your seat]
```

## Quality checks before output
- [ ] Every claim is provable — cite from BRAND.md proof points or mark as [NEEDS PROOF]
- [ ] No hyperbolic language ("revolutionary", "game-changing") unless BRAND.md explicitly approves
- [ ] Urgency/scarcity is real, not manufactured
- [ ] CTA is one action, specific, low-friction
- [ ] Terminology matches BRAND.md table
- [ ] Compliance lines added if BRAND.md Compliance section requires them
- [ ] Length matches channel in BRAND.md Channels table
