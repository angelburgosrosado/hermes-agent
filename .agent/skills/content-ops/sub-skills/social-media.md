# Sub-skill: Social Media Copy

Generates platform-native posts, captions, and series for LinkedIn, Instagram, X/Twitter, and Facebook.
Always read `BRAND.md` in full before generating any content.

## When to use
- Organic social posts (educational, product, cultural)
- Caption writing for visual content
- Series/thread planning
- Repurposing long-form content into social-native formats
- Event and launch social content

## Platform constraints

| Platform | Tone | Length | Format notes |
|---------|------|--------|-------------|
| LinkedIn | Professional, insight-led | 150-300 words | Hook on line 1 (before "see more"). No hashtag dumps — max 3. |
| Instagram | Visual-first, punchy | Caption ≤80 words | Emoji allowed if BRAND.md approves. CTA in last line. |
| X/Twitter | Terse, opinionated | ≤280 chars per tweet | Threads: hook tweet + 4-7 supporting tweets. |
| Facebook | Conversational, community | 40-80 words | Question-based CTA performs well. |

## Post formats

### LinkedIn educational post (highest organic reach format)
```
[Hook — one bold, specific, or counterintuitive statement. ≤12 words. No period at end.]

[Line break]

[Context — why this matters. 2-3 sentences.]

[List or breakdown — 3-5 bullets or numbered points]
- [Point 1]
- [Point 2]
- [Point 3]

[Synthesis — one takeaway sentence]

[CTA — question or soft ask: "What's your take?" / "Save this for later." / "Link in comments."]

[1-3 hashtags max — niche > broad]
```

### Instagram caption
```
[Visual description isn't needed — the image handles it]
[Line 1: Punchy opener that earns the "more" tap]
[Lines 2-3: Benefit or context — brief]
[CTA: "Save this." / "Tag someone who needs this." / "Link in bio for [X]."]
[Hashtags on separate line or first comment — max 10, mix niche + broad]
```

### X/Twitter thread
```
Tweet 1 (hook):    [Bold claim or counterintuitive insight. "A thread:" or "🧵" optional.]
Tweet 2:           [Proof or context for claim]
Tweets 3-6:        [Supporting points — each stands alone, each adds new info]
Final tweet:       [Summary + CTA: "Follow for more on [topic]" or "Share if useful"]
```

## Content pillars (fill in from BRAND.md)
Every post should belong to one pillar. Rotate across pillars for variety:
1. **Educational** — teaches something from your domain expertise
2. **Product** — shows what your product does (demo, feature, update)
3. **Proof** — customer stories, case studies, results
4. **Culture/Behind-the-scenes** — who you are, how you work
5. **Community** — engagement prompts, polls, questions

## Quality checks before output
- [ ] Hook stands alone — if only the first line is read, is it worth reading?
- [ ] Platform character/word limit respected
- [ ] One CTA per post — not "comment, like, share, and follow"
- [ ] Terminology matches BRAND.md table
- [ ] Hashtag count within platform limit
- [ ] Emoji usage consistent with BRAND.md voice rules
- [ ] Post belongs to a content pillar
